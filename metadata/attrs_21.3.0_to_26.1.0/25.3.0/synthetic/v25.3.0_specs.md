# Upgrade Specification from 25.2.0 to 25.3.0

## Bug Fixes

### Task 1 Restore generator-based field_transformer support
Ensure that upgrading to 25.3.0 restores support for `field_transformer` callables that return generators or other one-pass iterables, so attrs-based class creation behaves the same as it did before the 25.2.0 regression.

- **Expectation**: Users should be able to supply `field_transformer` logic as a generator-producing callable and have class creation complete normally, with the yielded fields treated the same way as fields returned in a pre-built collection.

- **Constraints**: The upgrade should broaden compatibility back to generator-style transformers without changing how already-supported transformers behave or weakening normal validation of the resulting fields.
