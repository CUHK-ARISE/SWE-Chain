# Upgrade Specification from 2.12.0 to 2.12.1

## Bug Fixes

### Task 1 Restore full configuration reset behavior for conan config clean
Ensure that `conan config clean` performs a complete configuration reset so Conan can regenerate every required default configuration artifact after the clean, while preserving the package storage area.

- **Expectation**: A configuration clean should act like a true reset of the user's Conan setup. After cleaning, Conan should rebuild any required default configuration structure instead of assuming it is still present, and the package cache itself should not be removed.

- **Constraints**: The clean operation should reset configuration metadata without turning into a package cache wipe or changing unrelated Conan behavior.


### Task 2 Preserve user-modified compatibility plugins during 2.12.1 migration
Ensure that upgrading to Conan 2.12.1 does not overwrite or remove user-customized compatibility plugin files when applying the 2.12 compatibility migration.

- **Expectation**: When users upgrade, Conan should only perform the compatibility plugin migration on untouched default files. Any user-edited compatibility customization must be preserved, and the upgrade must not partially rewrite one compatibility file while leaving or deleting the other.

- **Constraints**: The fix must prevent loss of user customizations and avoid partial migrations, while still allowing automatic cleanup and consolidation for default, tool-managed compatibility files.
