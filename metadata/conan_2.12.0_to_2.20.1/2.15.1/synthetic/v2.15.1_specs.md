# Upgrade Specification from 2.15.0 to 2.15.1

## New Features

### Task 1 Update Apple platform and Apple Clang 17 support
Ensure that Conan 2.15.1 recognizes the latest supported Apple platform, SDK, and Apple Clang versions, and that using apple-clang 17 produces an appropriate default C++ standard for modern Apple toolchains.

- **Expectation**: Users targeting current Apple operating systems, SDKs, and Xcode toolchains should be able to declare those versions directly in Conan settings without unsupported-version failures. When Conan infers the default C++ standard for Apple Clang 17, it should choose a more modern default than older Apple Clang releases.

- **Constraints**: The upgrade must preserve backward compatibility for existing Apple configurations while adding support for newer Apple releases. Only the newly supported Apple versions and the default C++ standard for the newest Apple Clang generation should change; unrelated platform and compiler behavior should continue to work as before.
