# Upgrade Specification from 2.16.0 to 2.16.1

## Bug Fixes

### Task 1 Recognize GCC 15 in default compiler settings
Ensure that GCC 15 is accepted as a valid compiler version in the default settings so users working with GCC 15 can use detected or declared compiler settings without version-validation failures.

- **Expectation**: Users on GCC 15 should be able to rely on the tool's standard compiler settings and automatic environment detection without the tool rejecting the compiler version as unknown or unsupported.

- **Constraints**: The upgrade should only remove the compatibility gap for GCC 15 and should not alter how other compiler versions are interpreted or validated.
