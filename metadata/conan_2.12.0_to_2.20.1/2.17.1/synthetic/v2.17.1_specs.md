# Upgrade Specification from 2.17.0 to 2.17.1

## Bug Fixes

### Task 1 Restore Git() remote commit checks on Git versions earlier than 2.36
Ensure that Conan's `Git()` helper can determine whether a commit exists in a remote repository when running with Git versions earlier than 2.36, while preserving the existing success and failure contract of the remote existence check.

- **Expectation**: Remote commit existence checks should keep working across supported Git versions. Users should receive the same observable yes or no result even on older Git installations, without changing their Conan workflow.

- **Constraints**: The fix should stay limited to compatibility for remote commit detection, preserve current behavior on newer environments, and avoid turning a boolean capability check into an unexpected hard failure.
