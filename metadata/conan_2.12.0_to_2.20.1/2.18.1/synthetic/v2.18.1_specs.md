# Upgrade Specification from 2.18.0 to 2.18.1

## Bug Fixes

### Task 1 Stop caching missing remote package lookups
Ensure that missing-package remote lookups are not remembered as persistent failures within a client session, so later requests can detect newly available packages and remote resolution does not retain unnecessary failure state.

- **Expectation**: When the client asks a remote for the latest package reference, successful answers may be reused, but a missing-package result must be retried on later requests instead of being treated as a permanent cached failure for that process. Package availability changes on the remote should be observable on a later lookup without extra cache-reset steps.

- **Constraints**: Preserve existing behavior for normal successful resolution and one-off failures, while removing only the persistence of failed missing-package lookups across repeated calls. The upgrade should not add new caller actions or configuration requirements.
