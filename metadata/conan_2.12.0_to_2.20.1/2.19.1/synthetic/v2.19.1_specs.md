# Upgrade Specification from 2.19.0 to 2.19.1

## Bug Fixes

### Task 1 Stop forcing CMake try-compile configuration in CMakeToolchain
Ensure that upgrading to 2.19.1 stops CMakeToolchain from forcing a try-compile configuration so MSVC projects using legacy CMake probe logic continue to configure correctly.

- **Expectation**: Generated CMake toolchains should let try-compile checks use the normal CMake or user-provided configuration behavior instead of forcing Conan's selected build configuration. This should remove the MSVC compatibility issue seen in older CMake feature-detection logic.

- **Constraints**: This upgrade should only relax Conan's control over try-compile configuration. It should not require consumers to adopt a new interface or replace the removed behavior with another forced default.
