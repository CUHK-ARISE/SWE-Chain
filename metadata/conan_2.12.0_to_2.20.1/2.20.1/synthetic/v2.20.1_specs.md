# Upgrade Specification from 2.20.0 to 2.20.1

## Bug Fixes

### Task 1 Fix APT package detection for multiarch and arch-independent installs
Ensure that Conan's APT-based system package manager correctly recognizes already installed packages in multiarch and cross-building environments, including architecture-independent packages, so it does not misidentify valid installations or trigger unnecessary reinstalls.

- **Expectation**: When Conan uses APT to satisfy system requirements, it should correctly detect whether the required package is already installed for the intended architecture. Cross-builds must also accept architecture-independent packages as valid, and versioned requirements must only be skipped when both the package version and acceptable architecture match.

- **Constraints**: The update should reduce false negatives for already installed packages without relaxing package matching so far that wrong-architecture or wrong-version installations are accepted. Existing user-facing package declarations should continue to work as before.


### Task 2 Fix Apt multiarch package detection
Ensure that Conan's Apt-based system requirements handling correctly recognizes already installed packages in multiarch and cross-building environments, including architecture-independent packages, so matching packages are not reinstalled unnecessarily.

- **Expectation**: Conan should correctly detect existing Apt packages across multiarch environments. If the needed package is already installed for the relevant architecture, or is architecture-independent, Conan should consider the requirement fulfilled and avoid reinstalling it.

- **Constraints**: Do not relax package checks so much that incompatible installations are accepted. Only already compatible packages should block a new install, and version-specific requirements must still honor the requested version.
