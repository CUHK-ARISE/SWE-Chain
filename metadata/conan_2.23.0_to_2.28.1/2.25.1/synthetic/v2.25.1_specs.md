# Upgrade Specification from 2.25.0 to 2.25.1

## Bug Fixes

### Task 1 Harden Windows package storage replacement against antivirus locks
Ensure that package storage updates tolerate transient file-replacement failures on Windows, especially when antivirus software temporarily blocks access, and fail clearly if the replacement still cannot be completed.

- **Expectation**: Windows cache and package writes should automatically recover from short-lived file locks during replacement, but persistent replacement failures must still stop the operation with a clear error. Platforms not affected by this transient-lock handling should continue to fail fast on replacement errors.

- **Constraints**: The fix must improve resilience to temporary Windows-only interference without masking permanent storage errors, waiting indefinitely, or changing behavior on other operating systems beyond reporting true replacement failures as errors.
