# Upgrade Specification from 2.25.1 to 2.25.2

## Bug Fixes

### Task 1 Avoid antivirus-related failures during package binary downloads
Ensure that downloading a package binary into the local cache does not fail because publication of the downloaded package depends on an atomic replacement step that can be blocked by Windows antivirus or file locking. Ensure that interrupted or failed downloads are still treated as incomplete cache content rather than valid package binaries.

- **Expectation**: Package downloads should complete reliably even when antivirus or other background software briefly interferes with file operations. A package should only appear usable in the cache once its download has completed, and failed downloads should remain clearly incomplete.

- **Constraints**: The fix must improve reliability of package downloads without changing what a successful cached package means or allowing partial downloads to be mistaken for complete ones.
