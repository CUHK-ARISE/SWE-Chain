# Upgrade Specification from 2.26.0 to 2.26.1

## Bug Fixes

### Task 1 Stabilize platform requirement revisions without forcing new binaries
Ensure that upgrading to 2.26.1 does not create avoidable missing binaries for consumers that use platform requirements or platform tool requirements without an explicit revision, while preserving correct revision-aware behavior when a revision is explicitly declared.

- **Expectation**: Platform-supplied dependencies should resolve consistently as a specific dependency reference, including revision identity, but the system must not treat the implicit platform revision as a real recipe change that forces consumers to rebuild. If the user explicitly pins a revision, that explicit revision should still behave like a normal pinned revision.

- **Constraints**: The fix must preserve compatibility for existing platform-based consumers and avoid unnecessary rebuild churn. Only explicit user intent to pin a revision should change revision-sensitive identity; the implicit platform default should remain transparent for binary compatibility.
