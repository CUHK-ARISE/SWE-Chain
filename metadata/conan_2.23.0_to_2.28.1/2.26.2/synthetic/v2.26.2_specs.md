# Upgrade Specification from 2.26.1 to 2.26.2

## Bug Fixes

### Task 1 Handle corrupted recipes during cache integrity checks
Ensure that `conan cache check-integrity` handles corrupted cached recipes by reporting them as integrity errors instead of failing with an exception.

- **Expectation**: Cache integrity checks should gracefully detect corrupted recipes and present them as ordinary integrity failures. Users should see a clear corruption report for the affected recipe and still receive the command's normal integrity output instead of a crash.

- **Constraints**: The fix should only remove the crash path for corrupted recipes without altering normal successful checks or other established corruption reports.


### Task 2 Restore pass-through handling for CMakeToolchain variables
Ensure that values assigned through `CMakeToolchain.variables` are no longer automatically escaped during CMake toolchain generation, so user-supplied strings and CMake expressions are preserved as authored.

- **Expectation**: Toolchain variables should behave as pass-through inputs. After upgrading, Conan should stop rewriting the contents of variable values and should generate CMake output that reflects exactly what the user configured.

- **Constraints**: The fix should restore user control over variable content without altering how users declare toolchain variables or limiting supported value forms.
