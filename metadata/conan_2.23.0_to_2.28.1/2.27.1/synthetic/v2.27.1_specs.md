# Upgrade Specification from 2.27.0 to 2.27.1

## Bug Fixes

### Task 1 Restore NMake dependency define quote formatting
Ensure that upgrading from Conan 2.27.0 to 2.27.1 restores correct NMake formatting for dependency-provided string defines so textual macro values are passed in the quote form NMake expects, without changing the existing handling of numeric, hexadecimal, empty, or bare defines.

- **Expectation**: For NMake consumers, dependency macros with textual values should once again be generated as normal quoted string defines instead of over-escaped values. Other define forms should remain stable, and this update does not change the separate behavior of toolchain or profile supplied defines.

- **Constraints**: Keep existing NMake define behavior unchanged except for the regression affecting dependency string values, and do not treat this update as a full fix for toolchain/profile quoting issues.
