# Upgrade Specification from 2.28.0 to 2.28.1

## Bug Fixes

### Task 1 Fix uncached downloads without SHA-256
Ensure that downloads requested without a SHA-256 checksum still complete from their original URL when source caching behavior is configured, while avoiding unsafe cache use.

- **Expectation**: A download without a checksum should behave as a direct, uncached download from the requested source. Cache and backup-source features must not turn the missing checksum into a failed or redirected download, and users should receive a warning when caching was requested but cannot be used.

- **Constraints**: The fix must avoid storing unverifiable downloads and must not alter normal cached-download behavior for checksum-protected downloads or unrelated configuration validation.
