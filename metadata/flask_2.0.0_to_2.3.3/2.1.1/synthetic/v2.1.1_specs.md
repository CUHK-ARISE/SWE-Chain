# Upgrade Specification from 2.1.0 to 2.1.1

## Dependency Updates

### Task 1 Require compatible importlib-metadata on Python < 3.10
Ensure that environments running on Python versions earlier than 3.10 install a compatible importlib-metadata release so Flask CLI command discovery does not fail with a TypeError during startup.

- **Expectation**: Older Python environments should automatically receive a metadata library version that supports the framework's CLI command discovery behavior, so command startup and plugin loading work normally instead of crashing because of dependency incompatibility.

- **Constraints**: The fix should be limited to affected older runtimes, preserve existing command discovery behavior, and avoid introducing new behavior changes for newer Python versions.
