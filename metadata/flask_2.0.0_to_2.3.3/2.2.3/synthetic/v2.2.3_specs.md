# Upgrade Specification from 2.2.2 to 2.2.3

## Bug Fixes

### Task 1 Enable autoescaping by default for SVG templates
Ensure that SVG template files are autoescaped by default so dynamic content inserted into rendered SVG output is safely escaped and behaves consistently with other markup template types.

- **Expectation**: Applications rendering SVG templates should get the same default escaping behavior they already expect for other markup templates. Dynamic values containing markup-sensitive characters should render safely in SVG output without extra configuration.

- **Constraints**: This upgrade should add SVG to the existing safe default behavior without regressing current escaping behavior for other template types or changing how applications invoke template rendering.


### Task 2 Restore `flask run --debug` support
Ensure that the `flask run` command supports the documented `--debug` option so users can start the development server in debug mode without the command being rejected.

- **Expectation**: Users should be able to enable debug mode directly on `flask run` with the documented flag. The help text and the actual command behavior should agree.

- **Constraints**: Do not change the normal startup path for users who do not opt into debug mode. The fix should make the advertised flag usable and consistent, not redefine how the server runs.


## Typing Updates

### Task 3 Type template_folder as path-like
Ensure that applications and blueprints can provide template folder locations as either strings or path-like objects, so valid pathlib.Path usage is recognized as supported by the public API.

- **Expectation**: Template folder configuration should accept both plain string paths and modern path objects. Developers using pathlib.Path for template directories should be able to do so without the framework API signaling that the value is invalid.

- **Constraints**: The update should broaden accepted template path representations without changing existing behavior for current users or altering default template lookup configuration.
