# Upgrade Specification from 2.2.4 to 2.2.5

## Bug Fixes

### Task 1 Werkzeug 2.3.3 compatibility for Flask test client sessions
Ensure that Flask's test client continues to preserve session and cookie state correctly when upgrading to Werkzeug 2.3.3, without breaking compatibility with older supported Werkzeug releases.

- **Expectation**: Upgrading to this version should keep Flask's test client working across Werkzeug versions so that session changes made through client interactions continue to persist as cookies and remain available on later requests.

- **Constraints**: The compatibility fix must preserve existing session and cookie behavior across older and newer Werkzeug versions rather than only supporting one specific dependency version.


### Task 2 Correct session-driven Vary header behavior
Ensure that responses affected by session state are marked with `Vary: Cookie` whenever the session is accessed, modified in a way that removes the session cookie, or refreshed, so caches do not treat cookie-dependent responses as generic.

- **Expectation**: Any response whose behavior or headers depend on session cookies should advertise that dependency through `Vary: Cookie`, including read access, session clearing that removes the cookie, and automatic cookie refreshes.

- **Constraints**: Preserve existing cache-variation rules while adding cookie variation only for responses that actually depend on session cookie state.
