# Upgrade Specification from 2.3.0 to 2.3.1

## Bug Fixes

### Task 1 Restore deprecated Flask Markup export compatibility
Ensure that applications upgrading to Flask 2.3.1 can still access the deprecated `Markup` export from `flask`, so legacy code using `from flask import Markup` or `flask.Markup` does not break unexpectedly.

- **Expectation**: Codebases that still rely on the old `Markup` access path should keep running after the upgrade. The package should provide backward-compatible access to this deprecated symbol instead of failing during import or attribute lookup.

- **Constraints**: The fix should be narrowly scoped to compatibility for legacy `Markup` usage. It should not change what `Markup` does or expand the library's public behavior beyond restoring the deprecated alias.
