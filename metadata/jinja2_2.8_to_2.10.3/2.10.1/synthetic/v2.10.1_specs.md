# Upgrade Specification from 2.10 to 2.10.1

## Bug Fixes

### Task 1 Secure sandboxed handling of str.format_map
Ensure that SandboxedEnvironment safely handles str.format_map so untrusted format strings cannot use it to bypass sandbox restrictions or reach unsafe objects.

- **Expectation**: Using format_map inside the sandbox should be subject to the same security rules as using format. Allowed substitutions should continue to render normally, blocked lookups should not expose unsafe objects, and invalid format_map invocation patterns should fail as regular argument errors.

- **Constraints**: Keep existing sandboxed formatting behavior stable while closing the format_map security gap. Valid formatting output should remain compatible with prior sandbox behavior except where unsafe format_map access was previously allowed.
