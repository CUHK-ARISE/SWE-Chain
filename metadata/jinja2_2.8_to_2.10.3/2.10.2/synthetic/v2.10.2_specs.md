# Upgrade Specification from 2.10.1 to 2.10.2

## Bug Fixes

### Task 1 Remove Python 3.7 collection ABC deprecation warnings
Ensure that upgrading from 2.10.1 to 2.10.2 removes Python 3.7 deprecation warnings related to abstract collection types without changing how mapping-like and mutable container objects are recognized by the library.

- **Expectation**: The upgrade should eliminate deprecation noise on newer Python runtimes while keeping template behavior, mapping detection, and sandbox container classification consistent with previous releases.

- **Constraints**: The fix must be backward-compatible and should not introduce behavior changes other than stopping the deprecated collection ABC usage from surfacing warnings.


### Task 2 Prevent sandboxed range memory exhaustion on Python 2
Ensure that using `range(...)` inside a sandboxed template enforces the sandbox range-size limit safely on Python 2, so oversized ranges raise `OverflowError` instead of exhausting memory.

- **Expectation**: Sandboxed templates should support normal `range(...)` usage for allowed sizes, while oversized ranges are rejected predictably with `OverflowError` rather than causing excessive memory use.

- **Constraints**: Keep ordinary sandboxed range iteration working as before, and only block ranges that exceed the documented sandbox size limit.


### Task 3 Avoid debug-build crashes during traceback rewriting
Ensure that Jinja2 can rewrite template-related tracebacks on Python 3.7 and newer without crashing the interpreter, including on CPython debug builds, while preserving compatible traceback behavior on older supported Python versions.

- **Expectation**: Template and undefined-related failures should continue to produce usable Jinja2-managed tracebacks, but modern Python runtimes must no longer be destabilized by the traceback-rewriting step.

- **Constraints**: The fix must preserve existing error-reporting behavior and backward compatibility for older supported runtimes, and it must not replace the original crash with a new initialization or runtime failure.
