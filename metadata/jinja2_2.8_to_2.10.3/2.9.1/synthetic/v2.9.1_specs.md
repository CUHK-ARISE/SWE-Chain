# Upgrade Specification from 2.9 to 2.9.1

## Bug Fixes

### Task 1 Fix nested macro caller block scoping
Ensure that nested macro caller blocks resolve variables using the correct scope so that reusing the same identifiers across outer macros and inner caller blocks does not render the wrong value.

- **Expectation**: Nested macro callbacks should behave with consistent lexical scoping. Reusing variable names in inner and outer macro contexts must not cause rendered output to pull data from the wrong scope.

- **Constraints**: The change should be limited to correcting incorrect scope resolution. Existing macro rendering patterns should continue to work unless they were previously affected by this bug.
