# Upgrade Specification from 2.9.5 to 2.9.6

## Bug Fixes

### Task 1 Fix custom Context subclasses during inherited template rendering
Ensure that applications using a custom `Context` subclass through `Environment.context_class` can render inherited templates correctly when parent templates contain variable expressions, without failing during variable resolution.

- **Expectation**: Custom template context classes should remain compatible with normal template inheritance. If a child template extends a parent template that reads variables, rendering should behave the same as with the default context and should return the expected output instead of failing at runtime.

- **Constraints**: The upgrade should only remove the regression for custom context usage and must not change normal rendering results or introduce new differences between default and custom context behavior.
