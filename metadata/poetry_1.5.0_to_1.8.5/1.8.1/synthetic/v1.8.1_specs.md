# Upgrade Specification from 1.8.0 to 1.8.1

## Bug Fixes

### Task 1 Gracefully handle repositories that reject negative wheel range requests
Ensure that lazy wheel inspection continues to work when a package repository rejects negative HTTP range requests with unexpected error responses, rather than failing dependency resolution.

- **Expectation**: When a repository does not correctly support suffix range requests for wheel files, package metadata retrieval should gracefully fall back to a compatible path and continue resolving dependencies. Servers that are only indicating that the requested suffix is larger than the file should keep the prior successful behavior.

- **Constraints**: Keep normal lazy wheel behavior unchanged for compliant repositories and for ordinary small-file range handling. The fix should only broaden compatibility for repositories that answer unsupported suffix range probes with unexpected HTTP errors.


## Additional Changes
- Ensure that upgrading to Poetry 1.8.1 also upgrades the runtime packaging dependency to a version that supports Poetry's metadata parsing paths, so metadata-driven operations do not fail because packaging.metadata is unavailable.
- Ensure that user-facing references to the project's default Git branch use `main` instead of `master`, so users following repository or contribution guidance are directed to the correct branch.
