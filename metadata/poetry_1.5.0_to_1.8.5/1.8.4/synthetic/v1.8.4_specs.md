# Upgrade Specification from 1.8.3 to 1.8.4

## Additional Changes
- Ensure that the library officially supports use on Python 3.13 while preserving the existing behavior users rely on from version 1.8.3.
- Ensure that running poetry shell in untrusted projects is protected by requiring a virtualenv version that includes the upstream command injection mitigation.
- Ensure that Poetry Core recognizes Python 3.13 as an available Python version wherever it derives package Python classifiers or formats Python version constraints from its known-version list.
