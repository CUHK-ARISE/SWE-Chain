# Upgrade Specification from 1.8.4 to 1.8.5

## Bug Fixes

### Task 1 Tolerate minor METADATA version updates
Ensure that package inspection does not fail solely because a distribution uses an unknown minor package METADATA version, while still rejecting absent metadata versions and genuinely unsupported major metadata versions.

- **Expectation**: Users should be able to inspect or install packages that adopt a newer compatible metadata minor version without the operation failing only because the metadata specification advanced. Packages using invalid or incompatible metadata should still fail clearly.

- **Constraints**: Maintain strictness for incompatible metadata while adding forward compatibility for compatible minor metadata updates. Existing package metadata parsing should remain stable for already-supported distributions.


## Additional Changes
- Ensure that package inspection accepts distributions with METADATA 2.4 and forward-compatible minor metadata versions within an already supported metadata major series, while still rejecting missing or entirely unsupported metadata major versions.
