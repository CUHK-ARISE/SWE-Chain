# Upgrade Specification from 7.1.0 to 7.1.1

## Bug Fixes

### Task 1 Fix regression where conftest.py files outside source tree are not picked up
Ensure that conftest.py files located outside the project source tree (e.g. in site-packages or other external directories) are correctly discovered and loaded during test collection, reversing a regression introduced in 7.1.0. Specifically:
- Ensure conftest.py files in third-party package directories (such as site-packages) are picked up when they were previously working in versions prior to 7.1.0.
- Ensure conftest.py files that are descendants of the confcutdir continue to be loaded.
- Ensure conftest.py files in directories that are ancestors of the confcutdir continue to be excluded.
- Ensure custom markers, fixtures, and hooks defined in external conftest.py files are properly registered and available during test runs.

- **Expectation**: Conftest.py files should be discovered based on whether they sit above the confcutdir boundary in the directory hierarchy. Files in unrelated directory trees (such as installed packages) should be loaded normally, as they are neither within nor above the project's confcutdir. Only conftest.py files in ancestor directories of the confcutdir should be excluded from loading.

- **Constraints**: The confcutdir filtering boundary must continue to prevent conftest.py files above the project root from interfering with test collection. The fix must be a pure behavioral correction that restores pre-regression behavior without introducing new configuration options or changing the confcutdir contract.
