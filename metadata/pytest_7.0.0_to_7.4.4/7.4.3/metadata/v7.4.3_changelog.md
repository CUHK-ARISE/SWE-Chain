## pytest 7.4.3 (2023-10-24)[¶](#pytest-7-4-3-2023-10-24)

### Bug Fixes[¶](#id364)

- [#10447](https://github.com/pytest-dev/pytest/issues/10447): Markers are now considered in the reverse mro order to ensure base class markers are considered first – this resolves a regression.
- [#11239](https://github.com/pytest-dev/pytest/issues/11239): Fixed `:=` in asserts impacting unrelated test cases.
- [#11439](https://github.com/pytest-dev/pytest/issues/11439): Handled an edge case where [`sys.stderr`](https://docs.python.org/3/library/sys.html#sys.stderr) might already be closed when [Fault Handler](how-to/failures.html#faulthandler) is tearing down.
