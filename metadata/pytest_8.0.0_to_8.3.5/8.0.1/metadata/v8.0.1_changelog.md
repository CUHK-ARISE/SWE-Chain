## pytest 8.0.1 (2024-02-16)[¶](#pytest-8-0-1-2024-02-16)

### Bug Fixes[¶](#id306)

- [#11875](https://github.com/pytest-dev/pytest/issues/11875): Correctly handle errors from [`getpass.getuser()`](https://docs.python.org/3/library/getpass.html#getpass.getuser) in Python 3.13.
- [#11879](https://github.com/pytest-dev/pytest/issues/11879): Fix an edge case where `ExceptionInfo._stringify_exception` could crash [`pytest.raises()`](reference/reference.html#pytest.raises).
- [#11906](https://github.com/pytest-dev/pytest/issues/11906): Fix regression with [`pytest.warns()`](reference/reference.html#pytest.warns) using custom warning subclasses which have more than one parameter in their `__init__`.
- [#11907](https://github.com/pytest-dev/pytest/issues/11907): Fix a regression in pytest 8.0.0 whereby calling [`pytest.skip()`](reference/reference.html#pytest.skip) and similar control-flow exceptions within a [`pytest.warns()`](reference/reference.html#pytest.warns) block would get suppressed instead of propagating.
- [#11929](https://github.com/pytest-dev/pytest/issues/11929): Fix a regression in pytest 8.0.0 whereby autouse fixtures defined in a module get ignored by the doctests in the module.
- [#11937](https://github.com/pytest-dev/pytest/issues/11937): Fix a regression in pytest 8.0.0 whereby items would be collected in reverse order in some circumstances.
