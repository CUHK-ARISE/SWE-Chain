# Upgrade Specification from 8.1.1 to 8.1.2

## Bug Fixes

### Task 1 Prevent pytest.approx crashes for NumPy-convertible operands
Ensure that `pytest.approx()` handles failed NumPy-style comparisons against array-convertible non-ndarray objects without raising internal errors, and instead reports the mismatch using the converted array semantics.

- **Expectation**: Approximate comparisons for NumPy-like values should work consistently for custom objects that behave like arrays, even if they are not actual `ndarray` instances. If the comparison fails, users should see a normal assertion failure with meaningful mismatch details rather than an internal crash.

- **Constraints**: The update should remove the erroneous failure-reporting crash without altering the expected behavior of valid approximate comparisons or changing unrelated `pytest.approx()` semantics.
