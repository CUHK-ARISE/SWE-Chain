# Upgrade Specification from 8.3.0 to 8.3.2

## Bug Fixes

### Task 1 Restore automatic Conda environment exclusion during test collection
Ensure that pytest automatically recognizes Conda environments during test discovery so upgrading does not cause tests from installed dependencies inside the environment to be collected by default.

- **Expectation**: Pytest should once again ignore test files that live inside the active environment when that environment is managed by Conda, so normal project runs only collect the project's intended tests unless the user explicitly asks to include environment contents.

- **Constraints**: The fix should restore expected default collection boundaries without breaking existing virtualenv behavior or removing the ability for users to intentionally collect tests from inside environment directories.
