# Upgrade Specification from 2.2.1 to 2.2.2

## Bug Fixes

### Task 1 Strip Proxy-Authorization on cross-host redirects
Ensure that proxy credentials are not forwarded by default when urllib3 follows a redirect to a different host.

- **Expectation**: When following redirects across hosts, the library should protect proxy authentication credentials by excluding them from the redirected request unless the caller explicitly configures a different header removal policy.

- **Constraints**: The fix must improve default credential safety without removing caller control over redirect header handling or weakening existing protections for other sensitive headers.


### Task 2 Treat Negative Read Amounts as Unlimited
Ensure that urllib3 response read operations accept negative integer amt values as an unlimited read, equivalent to omitting amt or passing None.

- **Expectation**: Users can pass -1 or another negative read size to consume the remaining response body, consistent with common file-like object behavior, without receiving an unexpected exception.

- **Constraints**: The fix should only expand accepted read-size inputs; existing response streaming, decoding, chunking, and partial-read semantics should remain compatible.


## Typing Updates

### Task 3 Preserve subclass return types for copy-like APIs
Ensure that copy-like and state-advancing APIs that preserve the concrete object type at runtime also expose that same concrete type to static type checkers.

- **Expectation**: When users subclass retry or header dictionary objects, copying, incrementing, or merging them should preserve the subclass type in static typing just as the operations already do at runtime.

- **Constraints**: This is a typing correctness update only; existing working code should continue to behave the same while type checkers become more precise for subclasses.


## Additional Changes
- Make the protocol version associated with a response available on the response object itself and avoid relying on private connection state when logging response versions.
