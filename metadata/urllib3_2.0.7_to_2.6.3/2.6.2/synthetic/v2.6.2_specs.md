# Upgrade Specification from 2.6.1 to 2.6.2

## Bug Fixes

### Task 1 Drain decoder buffers for chunked responses
Ensure that compressed responses read through chunked transfer handling continue draining any pending decoder output before accepting more chunk bytes, so valid compressed chunked responses do not fail during decompression.

- **Expectation**: Reading a valid compressed chunked response should transparently return the full decompressed body, even when the decoder has already received compressed bytes but still has decompressed output pending. The caller should not see a decompression failure caused only by chunked reads advancing before the decoder buffer is drained.

- **Constraints**: Do not change successful streaming behavior or hide real decoding errors. Only valid compressed chunked responses with pending decoder output should gain reliability.
