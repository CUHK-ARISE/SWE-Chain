## v2022.11.0 (Nov 4, 2022)[#](#v2022-11-0-nov-4-2022)

This release brings a number of bugfixes and documentation improvements. Both text and HTML
reprs now have a new “Indexes” section, which we expect will help with development of new
Index objects. This release also features more support for the Python Array API.

Many thanks to the 16 contributors to this release: Daniel Goman, Deepak Cherian, Illviljan, Jessica Scheick, Justus Magin, Mark Harfouche, Maximilian Roos, Mick, Patrick Naylor, Pierre, Spencer Clark, Stephan Hoyer, Tom Nicholas, Tom White

### New Features[#](#id664)

- Add static typing to plot accessors ([GH6949](https://github.com/pydata/xarray/issues/6949), [PR7052](https://github.com/pydata/xarray/pull/7052)). By [Michael Niklas](https://github.com/headtr1ck).
- Display the indexes in a new section of the text and HTML reprs ([PR6795](https://github.com/pydata/xarray/pull/6795), [PR7183](https://github.com/pydata/xarray/pull/7183), [PR7185](https://github.com/pydata/xarray/pull/7185)) By [Justus Magin](https://github.com/keewis) and [Benoît Bovy](https://github.com/benbovy).
- Added methods `DataArrayGroupBy.cumprod()` and `DatasetGroupBy.cumprod()`. ([PR5816](https://github.com/pydata/xarray/pull/5816)) By [Patrick Naylor](https://github.com/patrick-naylor)

### Breaking changes[#](#id668)

- `repr(ds)` may not show the same result because it doesn’t load small, lazy data anymore. Use `ds.head().load()` when wanting to see just a sample of the data. ([GH6722](https://github.com/pydata/xarray/issues/6722), [PR7203](https://github.com/pydata/xarray/pull/7203)). By [Jimmy Westling](https://github.com/illviljan).
- Many arguments of plotmethods have been made keyword-only.
- `xarray.plot.plot` module renamed to `xarray.plot.dataarray_plot` to prevent shadowing of the `plot` method. ([GH6949](https://github.com/pydata/xarray/issues/6949), [PR7052](https://github.com/pydata/xarray/pull/7052)). By [Michael Niklas](https://github.com/headtr1ck).

### Deprecations[#](#id671)

- Positional arguments for all plot methods have been deprecated ([GH6949](https://github.com/pydata/xarray/issues/6949), [PR7052](https://github.com/pydata/xarray/pull/7052)). By [Michael Niklas](https://github.com/headtr1ck).
- `xarray.plot.FacetGrid.axes` has been renamed to `xarray.plot.FacetGrid.axs` because it’s not clear if `axes` refers to single or multiple `Axes` instances. This aligns with `matplotlib.pyplot.subplots`. ([PR7194](https://github.com/pydata/xarray/pull/7194)) By [Jimmy Westling](https://github.com/illviljan).

### Bug fixes[#](#id674)

- Explicitly opening a file multiple times (e.g., after modifying it on disk) now reopens the file from scratch for h5netcdf and scipy netCDF backends, rather than reusing a cached version ([GH4240](https://github.com/pydata/xarray/issues/4240), [GH4862](https://github.com/pydata/xarray/issues/4862)). By [Stephan Hoyer](https://github.com/shoyer).
- Fixed bug where `Dataset.coarsen.construct()` would demote non-dimension coordinates to variables. ([PR7233](https://github.com/pydata/xarray/pull/7233)) By [Tom Nicholas](https://github.com/TomNicholas).
- Raise a TypeError when trying to plot empty data ([GH7156](https://github.com/pydata/xarray/issues/7156), [PR7228](https://github.com/pydata/xarray/pull/7228)). By [Michael Niklas](https://github.com/headtr1ck).

### Internal Changes[#](#id684)

- Doctests fail on any warnings ([PR7166](https://github.com/pydata/xarray/pull/7166)) By [Maximilian Roos](https://github.com/max-sixty).
- Improve import time by lazy loading `dask.distributed` ([PR7172](https://github.com/pydata/xarray/pull/7172)).
- Explicitly specify `longdouble=False` in [`cftime.date2num()`](https://unidata.github.io/cftime/api.html#cftime.date2num) when encoding times to preserve existing behavior and prevent future errors when it is eventually set to `True` by default in cftime ([PR7171](https://github.com/pydata/xarray/pull/7171)). By [Spencer Clark](https://github.com/spencerkclark).
- Improved import time by lazily importing backend modules, matplotlib, dask.array and flox. ([GH6726](https://github.com/pydata/xarray/issues/6726), [PR7179](https://github.com/pydata/xarray/pull/7179)) By [Michael Niklas](https://github.com/headtr1ck).
- Emit a warning under the development version of pandas when we convert non-nanosecond precision datetime or timedelta values to nanosecond precision. This was required in the past, because pandas previously was not compatible with non-nanosecond precision values. However pandas is currently working towards removing this restriction. When things stabilize in pandas we will likely consider relaxing this behavior in xarray as well ([GH7175](https://github.com/pydata/xarray/issues/7175), [PR7201](https://github.com/pydata/xarray/pull/7201)). By [Spencer Clark](https://github.com/spencerkclark).
