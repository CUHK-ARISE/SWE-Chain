## v2022.12.0 (2022 Dec 2)[#](#v2022-12-0-2022-dec-2)

This release includes a number of bug fixes and experimental support for Zarr V3.
Thanks to the 16 contributors to this release:
Deepak Cherian, Francesco Zanetta, Gregory Lee, Illviljan, Joe Hamman, Justus Magin, Luke Conibear, Mark Harfouche, Mathias Hauser,
Mick, Mike Taves, Sam Levang, Spencer Clark, Tom Nicholas, Wei Ji, templiert

### New Features[#](#id650)

- Enable using `offset` and `origin` arguments in [`DataArray.resample()`](generated/xarray.DataArray.resample.html#xarray.DataArray.resample) and [`Dataset.resample()`](generated/xarray.Dataset.resample.html#xarray.Dataset.resample) ([GH7266](https://github.com/pydata/xarray/issues/7266), [PR7284](https://github.com/pydata/xarray/pull/7284)). By [Spencer Clark](https://github.com/spencerkclark).
- Add experimental support for Zarr’s in-progress V3 specification. ([PR6475](https://github.com/pydata/xarray/pull/6475)). By [Gregory Lee](https://github.com/grlee77) and [Joe Hamman](https://github.com/jhamman).

### Deprecations[#](#id654)

- The PyNIO backend has been deprecated ([GH4491](https://github.com/pydata/xarray/issues/4491), [PR7301](https://github.com/pydata/xarray/pull/7301)). By [Joe Hamman](https://github.com/jhamman).

### Bug fixes[#](#id656)

- Fix handling of coordinate attributes in [`where()`](generated/xarray.where.html#xarray.where). ([GH7220](https://github.com/pydata/xarray/issues/7220), [PR7229](https://github.com/pydata/xarray/pull/7229)) By [Sam Levang](https://github.com/slevang).
- Import `nc_time_axis` when needed ([GH7275](https://github.com/pydata/xarray/issues/7275), [PR7276](https://github.com/pydata/xarray/pull/7276)). By [Michael Niklas](https://github.com/headtr1ck).
- Fix static typing of `xr.polyval()` ([GH7312](https://github.com/pydata/xarray/issues/7312), [PR7315](https://github.com/pydata/xarray/pull/7315)). By [Michael Niklas](https://github.com/headtr1ck).
- Fix multiple reads on fsspec S3 files by resetting file pointer to 0 when reading file streams ([GH6813](https://github.com/pydata/xarray/issues/6813), [PR7304](https://github.com/pydata/xarray/pull/7304)). By [David Hoese](https://github.com/djhoese) and [Wei Ji Leong](https://github.com/weiji14).
- Fix [`Dataset.assign_coords()`](generated/xarray.Dataset.assign_coords.html#xarray.Dataset.assign_coords) resetting all dimension coordinates to default (pandas) index ([GH7346](https://github.com/pydata/xarray/issues/7346), [PR7347](https://github.com/pydata/xarray/pull/7347)). By [Benoît Bovy](https://github.com/benbovy).
