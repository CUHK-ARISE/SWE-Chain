## v2023.01.0 (Jan 17, 2023)[#](#v2023-01-0-jan-17-2023)

This release includes a number of bug fixes. Thanks to the 14 contributors to this release:
Aron Gergely, Benoit Bovy, Deepak Cherian, Ian Carroll, Illviljan, Joe Hamman, Justus Magin, Mark Harfouche,
Matthew Roeschke, Paige Martin, Pierre, Sam Levang, Tom White,  stefank0.

### Breaking changes[#](#id642)

- [`CFTimeIndex.get_loc()`](generated/xarray.CFTimeIndex.get_loc.html#xarray.CFTimeIndex.get_loc) has removed the `method` and `tolerance` keyword arguments. Use `.get_indexer([key], method=..., tolerance=...)` instead ([PR7361](https://github.com/pydata/xarray/pull/7361)). By [Matthew Roeschke](https://github.com/mroeschke).

### Bug fixes[#](#id643)

- Avoid in-memory broadcasting when converting to a dask dataframe using `.to_dask_dataframe.` ([GH6811](https://github.com/pydata/xarray/issues/6811), [PR7472](https://github.com/pydata/xarray/pull/7472)). By [Jimmy Westling](https://github.com/illviljan).
- Accessing the property `.nbytes` of a DataArray, or Variable no longer accidentally triggers loading the variable into memory.
- Allow numpy-only objects in [`where()`](generated/xarray.where.html#xarray.where) when `keep_attrs=True` ([GH7362](https://github.com/pydata/xarray/issues/7362), [PR7364](https://github.com/pydata/xarray/pull/7364)). By [Sam Levang](https://github.com/slevang).
- add a `keep_attrs` parameter to [`Dataset.pad()`](generated/xarray.Dataset.pad.html#xarray.Dataset.pad), [`DataArray.pad()`](generated/xarray.DataArray.pad.html#xarray.DataArray.pad), and [`Variable.pad()`](generated/xarray.Variable.pad.html#xarray.Variable.pad) ([PR7267](https://github.com/pydata/xarray/pull/7267)). By [Justus Magin](https://github.com/keewis).
- Fixed performance regression in alignment between indexed and non-indexed objects of the same shape ([PR7382](https://github.com/pydata/xarray/pull/7382)). By [Benoît Bovy](https://github.com/benbovy).
- Preserve original dtype on accessing MultiIndex levels ([GH7250](https://github.com/pydata/xarray/issues/7250), [PR7393](https://github.com/pydata/xarray/pull/7393)). By [Ian Carroll](https://github.com/itcarroll).

### Internal Changes[#](#id648)

- Add the pre-commit hook `absolufy-imports` to convert relative xarray imports to absolute imports ([PR7204](https://github.com/pydata/xarray/pull/7204), [PR7370](https://github.com/pydata/xarray/pull/7370)). By [Jimmy Westling](https://github.com/illviljan).
