## v2023.02.0 (Feb 7, 2023)[#](#v2023-02-0-feb-7-2023)

This release brings a major upgrade to [`xarray.concat()`](generated/xarray.concat.html#xarray.concat), many bug fixes,
and a bump in supported dependency versions. Thanks to our 11 contributors:
Aron Gergely, Deepak Cherian, Illviljan, James Bourbeau, Joe Hamman,
Justus Magin, Hauke Schulz, Kai Mühlbauer, Ken Mankoff, Spencer Clark, Tom Nicholas.

### Breaking changes[#](#id634)

- Support for `python 3.8` has been dropped and the minimum versions of some dependencies were changed ([PR7461](https://github.com/pydata/xarray/pull/7461)):  | Package | Old | New | | --- | --- | --- | | python | 3.8 | 3.9 | | numpy | 1.20 | 1.21 | | pandas | 1.3 | 1.4 | | dask | 2021.11 | 2022.1 | | distributed | 2021.11 | 2022.1 | | h5netcdf | 0.11 | 0.13 | | lxml | 4.6 | 4.7 | | numba | 5.4 | 5.5 |

### Deprecations[#](#id635)

- Following pandas, the `closed` parameters of [`cftime_range()`](generated/xarray.cftime_range.html#xarray.cftime_range) and [`date_range()`](generated/xarray.date_range.html#xarray.date_range) are deprecated in favor of the `inclusive` parameters, and will be removed in a future version of xarray ([GH6985](https://github.com/pydata/xarray/issues/6985):, [PR7373](https://github.com/pydata/xarray/pull/7373)). By [Spencer Clark](https://github.com/spencerkclark).

### Bug fixes[#](#id637)

- [`xarray.concat()`](generated/xarray.concat.html#xarray.concat) can now concatenate variables present in some datasets but not others ([GH508](https://github.com/pydata/xarray/issues/508), [PR7400](https://github.com/pydata/xarray/pull/7400)). By [Kai Mühlbauer](https://github.com/kmuehlbauer) and [Scott Chamberlin](https://github.com/scottcha).
- Handle `keep_attrs` option in binary operators of [`Dataset()`](generated/xarray.Dataset.html#xarray.Dataset) ([GH7390](https://github.com/pydata/xarray/issues/7390), [PR7391](https://github.com/pydata/xarray/pull/7391)). By [Aron Gergely](https://github.com/arongergely).
- Improve error message when using dask in [`apply_ufunc()`](generated/xarray.apply_ufunc.html#xarray.apply_ufunc) with `output_sizes` not supplied. ([PR7509](https://github.com/pydata/xarray/pull/7509)) By [Tom Nicholas](https://github.com/TomNicholas).
- [`xarray.Dataset.to_zarr()`](generated/xarray.Dataset.to_zarr.html#xarray.Dataset.to_zarr) now drops variable encodings that have been added by xarray during reading a dataset. ([GH7129](https://github.com/pydata/xarray/issues/7129), [PR7500](https://github.com/pydata/xarray/pull/7500)). By [Hauke Schulz](https://github.com/observingClouds).

### Documentation[#](#id640)

- Mention the [flox package](https://flox.readthedocs.io) in GroupBy documentation and docstrings. By [Deepak Cherian](https://github.com/dcherian).
