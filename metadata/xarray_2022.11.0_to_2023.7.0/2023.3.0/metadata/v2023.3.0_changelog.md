## v2023.03.0 (March 22, 2023)[#](#v2023-03-0-march-22-2023)

This release brings many bug fixes, and some new features. The maximum pandas version is pinned to `<2` until we can support the new pandas datetime types.
Thanks to our 19 contributors:
Abel Aoun, Alex Goodman, Deepak Cherian, Illviljan, Jody Klymak, Joe Hamman, Justus Magin, Mary Gathoni, Mathias Hauser, Mattia Almansi, Mick, Oriol Abril-Pla, Patrick Hoefler, Paul Ockenfuß, Pierre, Shreyal Gupta, Spencer Clark, Tom Nicholas, Tom Vo

### New Features[#](#id616)

- Fix `xr.cov()` and `xr.corr()` now support complex valued arrays ([GH7340](https://github.com/pydata/xarray/issues/7340), [PR7392](https://github.com/pydata/xarray/pull/7392)). By [Michael Niklas](https://github.com/headtr1ck).
- Allow indexing along unindexed dimensions with dask arrays ([GH2511](https://github.com/pydata/xarray/issues/2511), [GH4276](https://github.com/pydata/xarray/issues/4276), [GH4663](https://github.com/pydata/xarray/issues/4663), [PR5873](https://github.com/pydata/xarray/pull/5873)). By [Abel Aoun](https://github.com/bzah) and [Deepak Cherian](https://github.com/dcherian).
- Support dask arrays in `first` and `last` reductions. By [Deepak Cherian](https://github.com/dcherian).
- Improved performance in `open_dataset` for datasets with large object arrays ([GH7484](https://github.com/pydata/xarray/issues/7484), [PR7494](https://github.com/pydata/xarray/pull/7494)). By [Alex Goodman](https://github.com/agoodm) and [Deepak Cherian](https://github.com/dcherian).

### Breaking changes[#](#id622)

### Deprecations[#](#id623)

- Following pandas, the `base` and `loffset` parameters of `xr.DataArray.resample()` and `xr.Dataset.resample()` have been deprecated and will be removed in a future version of xarray. Using the `origin` or `offset` parameters is recommended as a replacement for using the `base` parameter and using time offset arithmetic is recommended as a replacement for using the `loffset` parameter ([PR8459](https://github.com/pydata/xarray/pull/8459)). By [Spencer Clark](https://github.com/spencerkclark).

- Improve error message when using in [`Dataset.drop_vars()`](generated/xarray.Dataset.drop_vars.html#xarray.Dataset.drop_vars) to state which variables can’t be dropped. ([PR7518](https://github.com/pydata/xarray/pull/7518)) By [Tom Nicholas](https://github.com/TomNicholas).
- Require to explicitly defining optional dimensions such as hue and markersize for scatter plots. ([GH7314](https://github.com/pydata/xarray/issues/7314), [PR7277](https://github.com/pydata/xarray/pull/7277)). By [Jimmy Westling](https://github.com/illviljan).
- Fix matplotlib raising a UserWarning when plotting a scatter plot with an unfilled marker ([GH7313](https://github.com/pydata/xarray/issues/7313), [PR7318](https://github.com/pydata/xarray/pull/7318)). By [Jimmy Westling](https://github.com/illviljan).
- Fix issue with `max_gap` in `interpolate_na`, when applied to multidimensional arrays. ([GH7597](https://github.com/pydata/xarray/issues/7597), [PR7598](https://github.com/pydata/xarray/pull/7598)). By [Paul Ockenfuß](https://github.com/Ockenfuss).
- Fix [`DataArray.plot.pcolormesh()`](generated/xarray.DataArray.plot.pcolormesh.html#xarray.DataArray.plot.pcolormesh) which now works if one of the coordinates has str dtype ([GH6775](https://github.com/pydata/xarray/issues/6775), [PR7612](https://github.com/pydata/xarray/pull/7612)). By [Michael Niklas](https://github.com/headtr1ck).
