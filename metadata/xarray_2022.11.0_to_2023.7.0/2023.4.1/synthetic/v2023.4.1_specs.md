# Upgrade Specification from 2023.4.0 to 2023.4.1

## Bug Fixes

### Task 1 Fix groupby_bins ordering for unsorted binning coordinates
Ensure that bin-based grouping returns results in the correct bin order even when the grouped coordinate values are unsorted, so aggregated values remain aligned with their reported bins and match expected histogram-style counts.

- **Expectation**: Grouping data into bins should produce correctly ordered, correctly labeled results regardless of the original order of the grouping values. Users should see the same bin-to-value alignment they would expect from standard data analysis tools, including when custom labels are supplied.

- **Constraints**: The change should correct bin ordering without changing unrelated grouping rules, data shape preservation, or existing error cases. It should remain a compatibility fix rather than a new API behavior.
