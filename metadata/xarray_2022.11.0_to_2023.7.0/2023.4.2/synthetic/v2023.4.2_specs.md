# Upgrade Specification from 2023.4.1 to 2023.4.2

## Bug Fixes

### Task 1 Restore correct label-to-bin mapping in groupby_bins
Ensure that `groupby_bins` returns and exposes groups using the correct correspondence between each bin and its supplied label, so labeled bin aggregations and label-based group access produce the expected subset and counts.

- **Expectation**: Providing labels for bin-based grouping should behave exactly as users expect: each output group should represent the data that falls into that labeled bin. The library should not reshuffle labels based on lexical or numeric sorting, and all grouped operations should stay consistent with the visible labels.

- **Constraints**: The correction should be limited to the label-to-bin correspondence bug and should not introduce regressions in ordinary bin grouping, backend choice, or standard grouped reductions.


## Documentation

### Task 2 Document xarray string accessor examples and clarified behavior
Ensure that the xarray string accessor documentation clearly demonstrates how representative string methods behave on DataArray inputs, including case conversion, character classification, prefix and suffix matching, counting, and padding, so users can reliably understand expected outputs and edge cases when upgrading.

- **Expectation**: Users should be able to consult the library documentation and see clear, concrete examples of what common string accessor operations return, including transformed strings, boolean checks, counts, and broadcasted outputs. The documentation should also make clear that case folding can differ from ordinary lowercase conversion for some characters.

- **Constraints**: The release must improve understanding without changing how existing string APIs work in practice. Existing user code should continue to run the same way after the upgrade.
