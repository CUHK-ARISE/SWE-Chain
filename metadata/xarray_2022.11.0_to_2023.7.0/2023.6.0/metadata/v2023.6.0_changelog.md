## v2023.06.0 (June 21, 2023)[#](#v2023-06-0-june-21-2023)

This release adds features to `curvefit`, improves the performance of concatenation, and fixes various bugs.

Thank to our 13 contributors to this release:
Anderson Banihirwe, Deepak Cherian, dependabot[bot], Illviljan, Juniper Tyree, Justus Magin, Martin Fleischmann,
Mattia Almansi, mgunyho, Rutger van Haasteren, Thomas Nicholas, Tom Nicholas, Tom White.

### New Features[#](#id558)

- Added support for multidimensional initial guess and bounds in [`DataArray.curvefit()`](generated/xarray.DataArray.curvefit.html#xarray.DataArray.curvefit) ([GH7768](https://github.com/pydata/xarray/issues/7768), [PR7821](https://github.com/pydata/xarray/pull/7821)). By [András Gunyhó](https://github.com/mgunyho).
- Add an `errors` option to `Dataset.curve_fit()` that allows returning NaN for the parameters and covariances of failed fits, rather than failing the whole series of fits ([GH6317](https://github.com/pydata/xarray/issues/6317), [PR7891](https://github.com/pydata/xarray/pull/7891)). By [Dominik Stańczak](https://github.com/StanczakDominik) and [András Gunyhó](https://github.com/mgunyho).

### Breaking changes[#](#id561)

### Deprecations[#](#id562)

- Deprecate the [cdms2](https://github.com/CDAT/cdms) conversion methods ([PR7876](https://github.com/pydata/xarray/pull/7876)) By [Justus Magin](https://github.com/keewis).

### Performance[#](#id565)

- Improve concatenation performance ([GH7833](https://github.com/pydata/xarray/issues/7833), [PR7824](https://github.com/pydata/xarray/pull/7824)). By [Jimmy Westling](https://github.com/illviljan).

### Bug fixes[#](#id567)

- Fix bug where weighted `polyfit` were changing the original object ([GH5644](https://github.com/pydata/xarray/issues/5644), [PR7900](https://github.com/pydata/xarray/pull/7900)). By [Mattia Almansi](https://github.com/malmans2).
- Don’t call `CachingFileManager.__del__` on interpreter shutdown ([GH7814](https://github.com/pydata/xarray/issues/7814), [PR7880](https://github.com/pydata/xarray/pull/7880)). By [Justus Magin](https://github.com/keewis).
- Preserve vlen dtype for empty string arrays ([GH7328](https://github.com/pydata/xarray/issues/7328), [PR7862](https://github.com/pydata/xarray/pull/7862)). By [Tom White](https://github.com/tomwhite) and [Kai Mühlbauer](https://github.com/kmuehlbauer).
- Ensure dtype of reindex result matches dtype of the original DataArray ([GH7299](https://github.com/pydata/xarray/issues/7299), [PR7917](https://github.com/pydata/xarray/pull/7917)) By [Anderson Banihirwe](https://github.com/andersy005).
- Fix bug where a zero-length zarr `chunk_store` was ignored as if it was `None` ([PR7923](https://github.com/pydata/xarray/pull/7923)) By [Juniper Tyree](https://github.com/juntyr).

### Internal Changes[#](#id574)

- Minor improvements to support of the python [array api standard](https://data-apis.org/array-api/latest/), internally using the function `xp.astype()` instead of the method `arr.astype()`, as the latter is not in the standard. ([PR7847](https://github.com/pydata/xarray/pull/7847)) By [Tom Nicholas](https://github.com/TomNicholas).
- Xarray now uploads nightly wheels to [https://pypi.anaconda.org/scientific-python-nightly-wheels/simple/](https://pypi.anaconda.org/scientific-python-nightly-wheels/simple/) ([GH7863](https://github.com/pydata/xarray/issues/7863), [PR7865](https://github.com/pydata/xarray/pull/7865)). By [Martin Fleischmann](https://github.com/martinfleis).
- Stop uploading development wheels to TestPyPI ([PR7889](https://github.com/pydata/xarray/pull/7889)) By [Justus Magin](https://github.com/keewis).
- Added an exception catch for `AttributeError` along with `ImportError` when duck typing the dynamic imports in pycompat.py. This catches some name collisions between packages. ([GH7870](https://github.com/pydata/xarray/issues/7870), [PR7874](https://github.com/pydata/xarray/pull/7874))
