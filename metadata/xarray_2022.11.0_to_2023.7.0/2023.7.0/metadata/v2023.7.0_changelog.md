## v2023.07.0 (July 17, 2023)[#](#v2023-07-0-july-17-2023)

This release brings improvements to the documentation on wrapping numpy-like arrays, improved docstrings, and bug fixes.

### Deprecations[#](#id547)

- `hue_style` is being deprecated for scatter plots. ([GH7907](https://github.com/pydata/xarray/issues/7907), [PR7925](https://github.com/pydata/xarray/pull/7925)). By [Jimmy Westling](https://github.com/illviljan).

### Bug fixes[#](#id549)

- Ensure no forward slashes in variable and dimension names for HDF5-based engines. ([GH7943](https://github.com/pydata/xarray/issues/7943), [PR7953](https://github.com/pydata/xarray/pull/7953)) By [Kai Mühlbauer](https://github.com/kmuehlbauer).

### Documentation[#](#id551)

- Added examples to docstrings of [`Dataset.assign_attrs()`](generated/xarray.Dataset.assign_attrs.html#xarray.Dataset.assign_attrs), [`Dataset.broadcast_equals()`](generated/xarray.Dataset.broadcast_equals.html#xarray.Dataset.broadcast_equals), [`Dataset.equals()`](generated/xarray.Dataset.equals.html#xarray.Dataset.equals), [`Dataset.identical()`](generated/xarray.Dataset.identical.html#xarray.Dataset.identical), [`Dataset.expand_dims()`](generated/xarray.Dataset.expand_dims.html#xarray.Dataset.expand_dims), [`Dataset.drop_vars()`](generated/xarray.Dataset.drop_vars.html#xarray.Dataset.drop_vars) ([GH6793](https://github.com/pydata/xarray/issues/6793), [PR7937](https://github.com/pydata/xarray/pull/7937)) By [Harshitha](https://github.com/harshitha1201).
- Added page on wrapping chunked numpy-like arrays as alternatives to dask arrays. ([PR7951](https://github.com/pydata/xarray/pull/7951)) By [Tom Nicholas](https://github.com/TomNicholas).
- Expanded the page on wrapping numpy-like “duck” arrays. ([PR7911](https://github.com/pydata/xarray/pull/7911)) By [Tom Nicholas](https://github.com/TomNicholas).
- Added examples to docstrings of [`Dataset.isel()`](generated/xarray.Dataset.isel.html#xarray.Dataset.isel), [`Dataset.reduce()`](generated/xarray.Dataset.reduce.html#xarray.Dataset.reduce), [`Dataset.argmin()`](generated/xarray.Dataset.argmin.html#xarray.Dataset.argmin), [`Dataset.argmax()`](generated/xarray.Dataset.argmax.html#xarray.Dataset.argmax) ([GH6793](https://github.com/pydata/xarray/issues/6793), [PR7881](https://github.com/pydata/xarray/pull/7881)) By [Harshitha](https://github.com/harshitha1201) .

### Internal Changes[#](#id556)

- Allow chunked non-dask arrays (i.e. Cubed arrays) in groupby operations. ([PR7941](https://github.com/pydata/xarray/pull/7941)) By [Tom Nicholas](https://github.com/TomNicholas).
