## v2025.11.0 (Nov 17, 2025)[#](#v2025-11-0-nov-17-2025)

This release changes the default for `keep_attrs` such that attributes are preserved by default, adds support for [`DataTree`](generated/xarray.DataTree.html#xarray.DataTree) in top-level functions, and contains several memory and performance improvements as well as a number of bug fixes.

### New Features[#](#id44)

- [`merge()`](generated/xarray.merge.html#xarray.merge) and [`concat()`](generated/xarray.concat.html#xarray.concat) now support [`DataTree`](generated/xarray.DataTree.html#xarray.DataTree) objects ([GH9790](https://github.com/pydata/xarray/issues/9790), [GH9778](https://github.com/pydata/xarray/issues/9778)). By [Stephan Hoyer](https://github.com/shoyer).
- The `h5netcdf` engine has support for pseudo `NETCDF4_CLASSIC` files, meaning variables and attributes are cast to supported types. Note that the saved files won’t be recognized as genuine `NETCDF4_CLASSIC` files until `h5netcdf` adds support with version 1.7.0 ([GH10676](https://github.com/pydata/xarray/issues/10676), [PR10686](https://github.com/pydata/xarray/pull/10686)). By [David Huard](https://github.com/huard).
- Support comparing [`DataTree`](generated/xarray.DataTree.html#xarray.DataTree) objects with [`testing.assert_allclose()`](generated/xarray.testing.assert_allclose.html#xarray.testing.assert_allclose) ([PR10887](https://github.com/pydata/xarray/pull/10887)). By [Justus Magin](https://github.com/keewis).
- Add support for `chunks="auto"` for cftime datasets ([GH9834](https://github.com/pydata/xarray/issues/9834), [PR10527](https://github.com/pydata/xarray/pull/10527)). By [Charles Turner](https://github.com/charles-turner-1).

### Breaking Changes[#](#id47)

- All xarray operations now preserve attributes by default ([GH3891](https://github.com/pydata/xarray/issues/3891), [GH2582](https://github.com/pydata/xarray/issues/2582)). Previously, operations would drop attributes unless explicitly told to preserve them via `keep_attrs=True`. Additionally, when attributes are preserved in binary operations, they now combine attributes from both operands using `drop_conflicts` (keeping matching attributes, dropping conflicts), instead of keeping only the left operand’s attributes.  **What changed:**  # Before (xarray <2025.11.0): data = xr.DataArray([1, 2, 3], attrs={"units": "meters", "long_name": "height"}) result = data.mean() result.attrs # {} - Attributes lost! # After (xarray ≥2025.09.1): data = xr.DataArray([1, 2, 3], attrs={"units": "meters", "long_name": "height"}) result = data.mean() result.attrs # {"units": "meters", "long_name": "height"} - Attributes preserved!  **Affected operations include:**  *Computational operations:*  
  - Reductions: `mean()`, `sum()`, `std()`, `var()`, `min()`, `max()`, `median()`, `quantile()`, etc.
  - Rolling windows: `rolling().mean()`, `rolling().sum()`, etc.
  - Groupby: `groupby().mean()`, `groupby().sum()`, etc.
  - Resampling: `resample().mean()`, etc.
  - Weighted: `weighted().mean()`, `weighted().sum()`, etc.
  - `apply_ufunc()` and NumPy universal functions *Binary operations:*  
  - Arithmetic: `+`, `-`, `*`, `/`, `**`, `//`, `%` (combines attributes using `drop_conflicts`)
  - Comparisons: `<`, `>`, `==`, `!=`, `<=`, `>=` (combines attributes using `drop_conflicts`)
  - With scalars: `data * 2`, `10 - data` (preserves data’s attributes) *Data manipulation:*  
  - Missing data: `fillna()`, `dropna()`, `interpolate_na()`, `ffill()`, `bfill()`
  - Indexing/selection: `isel()`, `sel()`, `where()`, `clip()`
  - Alignment: `interp()`, `reindex()`, `align()`
  - Transformations: `map()`, `pipe()`, `assign()`, `assign_coords()`
  - Shape operations: `expand_dims()`, `squeeze()`, `transpose()`, `stack()`, `unstack()` **Binary operations - combines attributes with** `drop_conflicts`:  a = xr.DataArray([1, 2], attrs={"units": "m", "source": "sensor_a"}) b = xr.DataArray([3, 4], attrs={"units": "m", "source": "sensor_b"}) (a + b).attrs # {"units": "m"} - Matching values kept, conflicts dropped (b + a).attrs # {"units": "m"} - Order doesn't matter for drop_conflicts  **How to restore previous behavior:**  
  - **Globally for your entire script:**  import xarray as xr xr.set_options(keep_attrs=False) # Affects all subsequent operations
  - **For specific operations:**  result = data.mean(dim="time", keep_attrs=False)
  - **For code blocks:**  with xr.set_options(keep_attrs=False): # All operations in this block drop attrs result = data1 + data2
  - **Remove attributes after operations:**  result = data.mean().drop_attrs() By [Maximilian Roos](https://github.com/max-sixty).

### Bug Fixes[#](#id49)

- Fix h5netcdf backend for format=None, use same rule as netcdf4 backend ([PR10859](https://github.com/pydata/xarray/pull/10859)). By [Kai Mühlbauer](https://github.com/kmuehlbauer).
- `netcdf4` and `pydap` backends now use stricter URL detection to avoid incorrectly claiming remote URLs. The `pydap` backend now only claims URLs with explicit DAP protocol indicators (`dap2://` or `dap4://` schemes, or `/dap2/` or `/dap4/` in the URL path). This prevents both backends from claiming remote Zarr stores and other non-DAP URLs without an explicit `engine=` argument ([PR10804](https://github.com/pydata/xarray/pull/10804)). By [Ian Hunt-Isaak](https://github.com/ianhi).
- Fix indexing with empty arrays for scipy & h5netcdf backends which now resolves to empty slices ([GH10867](https://github.com/pydata/xarray/issues/10867), [PR10870](https://github.com/pydata/xarray/pull/10870)). By [Kai Mühlbauer](https://github.com/kmuehlbauer)
- Fix error handling issue in `decode_cf_variables` when decoding fails - the exception is now re-raised correctly, with a note added about the variable name that caused the error ([GH10873](https://github.com/pydata/xarray/issues/10873), [PR10886](https://github.com/pydata/xarray/pull/10886)). By [Jonas L. Bertelsen](https://github.com/jonaslb).
- Fix `equivalent` for numpy scalar nan comparison ([GH10833](https://github.com/pydata/xarray/issues/10833), [PR10838](https://github.com/pydata/xarray/pull/10838)). By [Maximilian Roos](https://github.com/max-sixty).
- Support non-`DataArray` outputs in [`Dataset.map()`](generated/xarray.Dataset.map.html#xarray.Dataset.map) ([GH10835](https://github.com/pydata/xarray/issues/10835), [PR10839](https://github.com/pydata/xarray/pull/10839)). By [Maximilian Roos](https://github.com/max-sixty).
- Support `drop_sel` on `MultiIndex` objects ([GH10862](https://github.com/pydata/xarray/issues/10862), [PR10863](https://github.com/pydata/xarray/pull/10863)). By [Aled Owen](https://github.com/owena11).
