## v2025.12.0 (Dec 5, 2025)[#](#v2025-12-0-dec-5-2025)

This release rolls back the default engine for HTTP urls, adds support for [`DataTree`](generated/xarray.DataTree.html#xarray.DataTree) objects in `combine_nested` and contains numerous bug fixes.

Thanks to the 16 contributors to this release:
Benoit Bovy, Christine P. Chai, Deepak Cherian, Dhruva Kumar Kaushal, Ian Hunt-Isaak, Ilan Gold, Illviljan, Julia Signell, Justus Magin, Lars Buntemeyer, Maximilian Roos, Miguel Jimenez, Nick Hodgskin, Richard Berg, Spencer Clark and Stephan Hoyer

### New Features[#](#id53)

- Improved `pydap` backend behavior and performance when using [`open_dataset()`](generated/xarray.open_dataset.html#xarray.open_dataset), [`open_datatree()`](generated/xarray.open_datatree.html#xarray.open_datatree) when downloading dap4 (opendap) dimensions data ([GH10628](https://github.com/pydata/xarray/issues/10628), [PR10629](https://github.com/pydata/xarray/pull/10629)). In addition `checksums=True|False` is added as optional argument to be passed to `pydap` backend. By [Miguel Jimenez-Urias](https://github.com/Mikejmnez).
- [`combine_nested()`](generated/xarray.combine_nested.html#xarray.combine_nested) now supports [`DataTree`](generated/xarray.DataTree.html#xarray.DataTree) objects ([PR10849](https://github.com/pydata/xarray/pull/10849)). By [Stephan Hoyer](https://github.com/shoyer).

### Bug Fixes[#](#id55)

- When assigning an indexed coordinate to a data variable or coordinate, coerce it from `IndexVariable` to `Variable` ([GH9859](https://github.com/pydata/xarray/issues/9859), [GH10829](https://github.com/pydata/xarray/issues/10829), [PR10909](https://github.com/pydata/xarray/pull/10909)). By [Julia Signell](https://github.com/jsignell).
- The NetCDF4 backend will now claim to be able to read any URL except for one that contains the substring zarr. This restores backward compatibility after [PR10804](https://github.com/pydata/xarray/pull/10804) broke workflows that relied on `xr.open_dataset("http://...")` ([PR10931](https://github.com/pydata/xarray/pull/10931)). By [Ian Hunt-Isaak](https://github.com/ianhi).
- Always normalize slices when indexing `LazilyIndexedArray` instances ([GH10941](https://github.com/pydata/xarray/issues/10941), [PR10948](https://github.com/pydata/xarray/pull/10948)). By [Justus Magin](https://github.com/keewis).
- Avoid casting custom indexes in `Dataset.drop_attrs` ([PR10961](https://github.com/pydata/xarray/pull/10961)) By [Justus Magin](https://github.com/keewis).
- Support decoding unsigned integers to `np.timedelta64`. By [Deepak Cherian](https://github.com/dcherian).
- Properly handle internal type promotion and `NA` objects for extension arrays ([PR10423](https://github.com/pydata/xarray/pull/10423)). By [Ilan Gold](https://github.com/ilan-gold).

### Documentation[#](#id61)

- Added section on the [limitations of cftime arithmetic](https://docs.xarray.dev/en/stable/user-guide/weather-climate.html#arithmetic-limitations-with-non-standard-calendars) ([PR10653](https://github.com/pydata/xarray/pull/10653)). By [Lars Buntemeyer](https://github.com/larsbuntemeyer).

### Internal Changes[#](#id62)

- Change the development workflow to use `pixi` ([GH10732](https://github.com/pydata/xarray/issues/10732), [PR10888](https://github.com/pydata/xarray/pull/10888)). By [Nick Nodgskin](https://github.com/VeckoTheGecko).
