## v2025.06.0 (Jun 10, 2025)[#](#v2025-06-0-jun-10-2025)

This release brings HTML reprs to the documentation, fixes to flexible Xarray indexes, performance optimizations, more ergonomic seasonal grouping and resampling
with new [`SeasonGrouper`](generated/xarray.groupers.SeasonGrouper.html#xarray.groupers.SeasonGrouper) and [`SeasonResampler`](generated/xarray.groupers.SeasonResampler.html#xarray.groupers.SeasonResampler) objects, and bugfixes.

### New Features[#](#id139)

- Switch docs to jupyter-execute sphinx extension for HTML reprs. ([GH3893](https://github.com/pydata/xarray/issues/3893), [PR10383](https://github.com/pydata/xarray/pull/10383)) By [Scott Henderson](https://github.com/scottyhq).
- Allow an Xarray index that uses multiple dimensions checking equality with another index for only a subset of those dimensions (i.e., ignoring the dimensions that are excluded from alignment). ([GH10243](https://github.com/pydata/xarray/issues/10243), [PR10293](https://github.com/pydata/xarray/pull/10293)) By [Benoit Bovy](https://github.com/benbovy).
- New [`SeasonGrouper`](generated/xarray.groupers.SeasonGrouper.html#xarray.groupers.SeasonGrouper) and [`SeasonResampler`](generated/xarray.groupers.SeasonResampler.html#xarray.groupers.SeasonResampler) objects for ergonomic seasonal aggregation. See the docs on [Handling Seasons](user-guide/time-series.html#seasonal-grouping) or [blog post](https://xarray.dev/blog/season-grouping) for more. By [Deepak Cherian](https://github.com/dcherian).
- Data corruption issues arising from misaligned Dask and Zarr chunks can now be prevented using the new `align_chunks` parameter in [`to_zarr()`](generated/xarray.DataArray.to_zarr.html#xarray.DataArray.to_zarr). This option automatically rechunk the Dask array to align it with the Zarr storage chunks. For now, it is disabled by default, but this could change on the future. ([GH9914](https://github.com/pydata/xarray/issues/9914), [PR10336](https://github.com/pydata/xarray/pull/10336)) By [Joseph Nowak](https://github.com/josephnowak).

### Bug fixes[#](#id144)

- Fix [`BinGrouper`](generated/xarray.groupers.BinGrouper.html#xarray.groupers.BinGrouper) when `labels` is not specified ([GH10284](https://github.com/pydata/xarray/issues/10284)). By [Deepak Cherian](https://github.com/dcherian).
- Allow accessing arbitrary attributes on Pandas ExtensionArrays. By [Deepak Cherian](https://github.com/dcherian).
- Fix coding empty (zero-size) timedelta64 arrays, `units` taking precedence when encoding, fallback to default values when decoding ([GH10310](https://github.com/pydata/xarray/issues/10310), [PR10313](https://github.com/pydata/xarray/pull/10313)). By [Kai Mühlbauer](https://github.com/kmuehlbauer).
- Use dtype from intermediate sum instead of source dtype or “int” for casting of count when calculating mean in rolling for correct operations (preserve float dtypes, correct mean of bool arrays) ([GH10340](https://github.com/pydata/xarray/issues/10340), [PR10341](https://github.com/pydata/xarray/pull/10341)). By [Kai Mühlbauer](https://github.com/kmuehlbauer).
- Improve the html `repr` of Xarray objects (dark mode, icons and variable attribute / data dropdown sections). ([PR10353](https://github.com/pydata/xarray/pull/10353), [PR10354](https://github.com/pydata/xarray/pull/10354)) By [Benoit Bovy](https://github.com/benbovy).
- Raise an error when attempting to encode [`numpy.datetime64`](https://numpy.org/doc/stable/reference/arrays.scalars.html#numpy.datetime64) values prior to the Gregorian calendar reform date of 1582-10-15 with a `"standard"` or `"gregorian"` calendar. Previously we would warn and encode these as `cftime.DatetimeGregorian` objects, but it is not clear that this is the user’s intent, since this implicitly converts the calendar of the datetimes from `"proleptic_gregorian"` to `"gregorian"` and prevents round-tripping them as [`numpy.datetime64`](https://numpy.org/doc/stable/reference/arrays.scalars.html#numpy.datetime64) values ([PR10352](https://github.com/pydata/xarray/pull/10352)). By [Spencer Clark](https://github.com/spencerkclark).
- Avoid unsafe casts from float to unsigned int in CFMaskCoder ([GH9815](https://github.com/pydata/xarray/issues/9815), [PR9964](https://github.com/pydata/xarray/pull/9964)). By ` Elliott Sales de Andrade <[QuLogic](https://github.com/QuLogic)>`_.

### Performance[#](#id151)

- Lazily indexed arrays now use less memory to store keys by avoiding copies in `VectorizedIndexer` and `OuterIndexer` ([GH10316](https://github.com/pydata/xarray/issues/10316)). By [Jesse Rusak](https://github.com/jder).
- Fix performance regression in interp where more data was loaded than was necessary. ([GH10287](https://github.com/pydata/xarray/issues/10287)). By [Deepak Cherian](https://github.com/dcherian).
- Speed up encoding of [`cftime.datetime`](https://unidata.github.io/cftime/api.html#cftime.datetime) objects by roughly a factor of three ([PR8324](https://github.com/pydata/xarray/pull/8324)). By [Antoine Gibek](https://github.com/antscloud).
