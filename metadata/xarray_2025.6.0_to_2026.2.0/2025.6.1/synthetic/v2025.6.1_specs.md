# Upgrade Specification from 2025.6.0 to 2025.6.1

## Dependency Updates

### Task 1 Remove runtime dependency on typing_extensions
Ensure that upgrading to 2025.6.1 no longer requires `typing_extensions` to be installed for normal runtime imports and use of the library, while preserving existing datetime accessor behavior and type annotation compatibility.

- **Expectation**: After the upgrade, users should be able to import and use the library normally without adding `typing_extensions` as a runtime dependency. Typing support should remain available to tools that analyze annotations, without changing user-visible datetime accessor behavior.

- **Constraints**: This should be a dependency cleanup only: existing datetime-related APIs should behave the same, and the upgrade should reduce installation/runtime requirements rather than introduce new usage constraints.


## Additional Changes
- Ensure that xarray correctly handles pandas extension arrays when converting from pandas objects into Variables and Datasets. Compatible extension arrays should retain their extension-array semantics through xarray storage and back to pandas, while unsupported extension-array implementations must be converted to plain NumPy arrays to avoid incorrect wrapping or indexing behavior.
