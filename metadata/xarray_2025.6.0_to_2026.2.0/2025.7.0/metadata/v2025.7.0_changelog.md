## v2025.07.0 (Jul 3, 2025)[#](#v2025-07-0-jul-3-2025)

This release extends xarray’s support for custom index classes, restores support for reading netCDF3 files with SciPy, updates minimum dependencies, and fixes a number of bugs.

Thanks to the 17 contributors to this release:
Bas Nijholt, Benoit Bovy, Deepak Cherian, Dhruva Kumar Kaushal, Dimitri Papadopoulos Orfanos, Ian Hunt-Isaak, Kai Mühlbauer, Mathias Hauser, Maximilian Roos, Miguel Jimenez, Nick Hodgskin, Scott Henderson, Shuhao Cao, Spencer Clark, Stephan Hoyer, Tom Nicholas and Zsolt Cserna

### New Features[#](#id122)

- Expose [`RangeIndex`](generated/xarray.indexes.RangeIndex.html#xarray.indexes.RangeIndex), and [`CoordinateTransformIndex`](generated/xarray.indexes.CoordinateTransformIndex.html#xarray.indexes.CoordinateTransformIndex) as public api under the `xarray.indexes` namespace. By [Deepak Cherian](https://github.com/dcherian).
- Support zarr-python’s new `.supports_consolidated_metadata` store property ([PR10457`](https://github.com/pydata/xarray/pull/10457`)). by [Tom Nicholas](https://github.com/TomNicholas).
- Better error messages when encoding data to be written to disk fails ([PR10464](https://github.com/pydata/xarray/pull/10464)). By [Stephan Hoyer](https://github.com/shoyer)

### Bug fixes[#](#id128)

- Fix Pydap test_cmp_local_file for numpy 2.3.0 changes, 1. do always return arrays for all versions and 2. skip astype(str) for numpy >= 2.3.0 for expected data. ([PR10421](https://github.com/pydata/xarray/pull/10421)) By [Kai Mühlbauer](https://github.com/kmuehlbauer).
- Fix the SciPy backend for netCDF3 files . ([GH8909](https://github.com/pydata/xarray/issues/8909), [PR10376](https://github.com/pydata/xarray/pull/10376)) By [Deepak Cherian](https://github.com/dcherian).
- Check and fix character array string dimension names, issue warnings as needed ([GH6352](https://github.com/pydata/xarray/issues/6352), [PR10395](https://github.com/pydata/xarray/pull/10395)). By [Kai Mühlbauer](https://github.com/kmuehlbauer).
- Fix the error message of [`testing.assert_equal()`](generated/xarray.testing.assert_equal.html#xarray.testing.assert_equal) when two different [`DataTree`](generated/xarray.DataTree.html#xarray.DataTree) objects are passed ([PR10440](https://github.com/pydata/xarray/pull/10440)). By [Mathias Hauser](https://github.com/mathause).
- Fix [`testing.assert_equal()`](generated/xarray.testing.assert_equal.html#xarray.testing.assert_equal) with `check_dim_order=False` for [`DataTree`](generated/xarray.DataTree.html#xarray.DataTree) objects ([PR10442](https://github.com/pydata/xarray/pull/10442)). By [Mathias Hauser](https://github.com/mathause).
- Fix Pydap backend testing. Now test forces string arrays to dtype “S” (pydap converts them to unicode type by default). Removes conditional to numpy version. ([GH10261](https://github.com/pydata/xarray/issues/10261), [PR10482](https://github.com/pydata/xarray/pull/10482)) By [Miguel Jimenez-Urias](https://github.com/Mikejmnez).
- Fix attribute overwriting bug when decoding encoded [`numpy.timedelta64`](https://numpy.org/doc/stable/reference/arrays.scalars.html#numpy.timedelta64) values from disk with a dtype attribute ([GH10468](https://github.com/pydata/xarray/issues/10468), [PR10469](https://github.com/pydata/xarray/pull/10469)). By [Spencer Clark](https://github.com/spencerkclark).
- Fix default `"_FillValue"` dtype coercion bug when encoding [`numpy.timedelta64`](https://numpy.org/doc/stable/reference/arrays.scalars.html#numpy.timedelta64) values to an on-disk format that only supports 32-bit integers ([GH10466](https://github.com/pydata/xarray/issues/10466), [PR10469](https://github.com/pydata/xarray/pull/10469)). By [Spencer Clark](https://github.com/spencerkclark).
