## v2025.07.1 (Jul 09, 2025)[#](#v2025-07-1-jul-09-2025)

This release brings a lot of improvements to flexible indexes functionality, including new classes
to ease building of new indexes with custom coordinate transforms ([`indexes.CoordinateTransformIndex`](generated/xarray.indexes.CoordinateTransformIndex.html#xarray.indexes.CoordinateTransformIndex))
and tree-like index structures ([`indexes.NDPointIndex`](generated/xarray.indexes.NDPointIndex.html#xarray.indexes.NDPointIndex)).
See a [new gallery](https://xarray-indexes.readthedocs.io) showing off the possibilities enabled by flexible indexes.

Thanks to the 7 contributors to this release:
Benoit Bovy, Deepak Cherian, Dhruva Kumar Kaushal, Dimitri Papadopoulos Orfanos, Illviljan, Justus Magin and Tom Nicholas

### New Features[#](#id113)

- New [`xarray.indexes.NDPointIndex`](generated/xarray.indexes.NDPointIndex.html#xarray.indexes.NDPointIndex), which by default uses [`scipy.spatial.KDTree`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.KDTree.html#scipy.spatial.KDTree) under the hood for the selection of irregular, n-dimensional data ([PR10478](https://github.com/pydata/xarray/pull/10478)). By [Benoit Bovy](https://github.com/benbovy).
- Allow skipping the creation of default indexes when opening datasets ([PR8051](https://github.com/pydata/xarray/pull/8051)). By [Benoit Bovy](https://github.com/benbovy) and [Justus Magin](https://github.com/keewis).

### Bug fixes[#](#id116)

- [`Dataset.set_xindex()`](generated/xarray.Dataset.set_xindex.html#xarray.Dataset.set_xindex) now raises a helpful error when a custom index creates extra variables that don’t match the provided coordinate names, instead of silently ignoring them. The error message suggests using the factory method pattern with [`xarray.Coordinates.from_xindex()`](generated/xarray.Coordinates.from_xindex.html#xarray.Coordinates.from_xindex) and [`Dataset.assign_coords()`](generated/xarray.Dataset.assign_coords.html#xarray.Dataset.assign_coords) for advanced use cases ([GH10499](https://github.com/pydata/xarray/issues/10499), [PR10503](https://github.com/pydata/xarray/pull/10503)). By [Dhruva Kumar Kaushal](https://github.com/dhruvak001).

### Documentation[#](#id118)

- A [new gallery](https://xarray-indexes.readthedocs.io) showing off the possibilities enabled by flexible indexes.

### Internal Changes[#](#id120)

- Refactored the `PandasIndexingAdapter` and `CoordinateTransformIndexingAdapter` internal indexing classes. Coordinate variables that wrap a [`pandas.RangeIndex`](https://pandas.pydata.org/pandas-docs/stable/reference/api/pandas.RangeIndex.html#pandas.RangeIndex), a [`pandas.MultiIndex`](https://pandas.pydata.org/pandas-docs/stable/reference/api/pandas.MultiIndex.html#pandas.MultiIndex) or a [`xarray.indexes.CoordinateTransform`](generated/xarray.indexes.CoordinateTransform.html#xarray.indexes.CoordinateTransform) are now displayed as lazy variables in the Xarray data reprs ([PR10355](https://github.com/pydata/xarray/pull/10355)). By [Benoit Bovy](https://github.com/benbovy).
