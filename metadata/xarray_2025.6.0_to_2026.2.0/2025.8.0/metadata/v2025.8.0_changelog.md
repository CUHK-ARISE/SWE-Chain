## v2025.08.0 (Aug 14, 2025)[#](#v2025-08-0-aug-14-2025)

This release brings the ability to load xarray objects asynchronously, write netCDF as bytes, fixes a number of bugs, and starts an important deprecation cycle for changing the default values of keyword arguments for various xarray combining functions.

Thanks to the 24 contributors to this release:
Alfonso Ladino, Brigitta Sipőcz, Claude, Deepak Cherian, Dimitri Papadopoulos Orfanos, Eric Jansen, Ian Hunt-Isaak, Ilan Gold, Illviljan, Julia Signell, Justus Magin, Kai Mühlbauer, Mathias Hauser, Matthew, Michael Niklas, Miguel Jimenez, Nick Hodgskin, Pratiman, Scott Staniewicz, Spencer Clark, Stephan Hoyer, Tom Nicholas, Yang Yang and jemmajeffree

### New Features[#](#id97)

- Added `DataTree.prune()` method to remove empty nodes while preserving tree structure. Useful for cleaning up DataTree after time-based filtering operations ([GH10590](https://github.com/pydata/xarray/issues/10590), [PR10598](https://github.com/pydata/xarray/pull/10598)). By [Alfonso Ladino](https://github.com/aladinor).
- Added new asynchronous loading methods `Dataset.load_async()`, `DataArray.load_async()`, [`Variable.load_async()`](generated/xarray.Variable.load_async.html#xarray.Variable.load_async). Note that users are expected to limit concurrency themselves - xarray does not internally limit concurrency in any way. ([GH10326](https://github.com/pydata/xarray/issues/10326), [PR10327](https://github.com/pydata/xarray/pull/10327)) By [Tom Nicholas](https://github.com/TomNicholas).
- [`DataTree.to_netcdf()`](generated/xarray.DataTree.to_netcdf.html#xarray.DataTree.to_netcdf) can now write to a file-like object, or return bytes if called without a filepath. ([GH10570](https://github.com/pydata/xarray/issues/10570)) By [Matthew Willson](https://github.com/mjwillson).
- Added exception handling for invalid files in [`open_mfdataset()`](generated/xarray.open_mfdataset.html#xarray.open_mfdataset). ([GH6736](https://github.com/pydata/xarray/issues/6736)) By [Pratiman Patel](https://github.com/pratiman-91).

### Breaking changes[#](#id100)

- When writing to NetCDF files with groups, Xarray no longer redefines dimensions that have the same size in parent groups ([GH10241](https://github.com/pydata/xarray/issues/10241)). This conforms with [CF Conventions for group scrope](https://cfconventions.org/cf-conventions/cf-conventions.html#_scope) but may require adjustments for code that consumes NetCDF files produced by Xarray. By [Stephan Hoyer](https://github.com/shoyer).

### Deprecations[#](#id102)

- Start a deprecation cycle for changing the default keyword arguments to [`concat()`](generated/xarray.concat.html#xarray.concat), [`merge()`](generated/xarray.merge.html#xarray.merge), [`combine_nested()`](generated/xarray.combine_nested.html#xarray.combine_nested), [`combine_by_coords()`](generated/xarray.combine_by_coords.html#xarray.combine_by_coords), and [`open_mfdataset()`](generated/xarray.open_mfdataset.html#xarray.open_mfdataset). Emits a [`FutureWarning`](https://docs.python.org/3/library/exceptions.html#FutureWarning) when using old defaults and new defaults would result in different behavior. Adds an option: `use_new_combine_kwarg_defaults` to opt in to new defaults immediately. New values are:  
  - `data_vars`: None which means `all` when concatenating along a new dimension, and `"minimal"` when concatenating along an existing dimension
  - `coords`: “minimal”
  - `compat`: “override”
  - `join`: “exact” ([GH8778](https://github.com/pydata/xarray/issues/8778), [GH1385](https://github.com/pydata/xarray/issues/1385), [PR10062](https://github.com/pydata/xarray/pull/10062)). By [Julia Signell](https://github.com/jsignell).

### Bug fixes[#](#id104)

- Fix Pydap Datatree backend testing. Testing now compares elements of (unordered) two sets (before, lists) ([PR10525](https://github.com/pydata/xarray/pull/10525)). By [Miguel Jimenez-Urias](https://github.com/Mikejmnez).
- Fix `KeyError` when passing a `dim` argument different from the default to `convert_calendar` ([PR10544](https://github.com/pydata/xarray/pull/10544)). By [Eric Jansen](https://github.com/ej81).
- Fix transpose of boolean arrays read from disk. ([GH10536](https://github.com/pydata/xarray/issues/10536)) By [Deepak Cherian](https://github.com/dcherian).
- Fix detection of the `h5netcdf` backend. Xarray now selects `h5netcdf` if the default `netCDF4` engine is not available ([GH10401](https://github.com/pydata/xarray/issues/10401), [PR10557](https://github.com/pydata/xarray/pull/10557)). By [Scott Staniewicz](https://github.com/scottstanie).
- Fix [`merge()`](generated/xarray.merge.html#xarray.merge) to prevent altering original object depending on join value ([PR10596](https://github.com/pydata/xarray/pull/10596)) By [Julia Signell](https://github.com/jsignell).
- Ensure `unlimited_dims` passed to [`xarray.DataArray.to_netcdf()`](generated/xarray.DataArray.to_netcdf.html#xarray.DataArray.to_netcdf), [`xarray.Dataset.to_netcdf()`](generated/xarray.Dataset.to_netcdf.html#xarray.Dataset.to_netcdf) or [`xarray.DataTree.to_netcdf()`](generated/xarray.DataTree.to_netcdf.html#xarray.DataTree.to_netcdf) only contains dimensions present in the object; raise `ValueError` otherwise ([GH10549](https://github.com/pydata/xarray/issues/10549), [PR10608](https://github.com/pydata/xarray/pull/10608)). By [Kai Mühlbauer](https://github.com/kmuehlbauer).
