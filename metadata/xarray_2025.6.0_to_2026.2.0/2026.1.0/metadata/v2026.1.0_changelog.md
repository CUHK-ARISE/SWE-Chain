## v2026.01.0 (Jan 28, 2026)[#](#v2026-01-0-jan-28-2026)

This release includes an improved DataTree HTML representation with collapsible groups and automatic truncation, easier selection on coordinates without explicit indexes, pandas 3 compatibility, and various bug fixes and performance improvements.

Thanks to the 25 contributors to this release:
Barron H. Henderson, Christine P. Chai, DHRUVA KUMAR KAUSHAL, David Bold, Davis Bennett, Deepak Cherian, Dhruva Kumar Kaushal, Florian Knappers, Ian Hunt-Isaak, Jacob Tomlinson, Joshua Gould, Julia Signell, Justus Magin, Lucas Colley, Mark Harfouche, Matthew, Maximilian Roos, Nick Hodgskin, Sakshee_D, Sam Levang, Samay Mehar, Simon Høxbro Hansen, Spencer Clark, Stephan Hoyer and knappersfy

### New Features[#](#id32)

- Improved [`DataTree`](generated/xarray.DataTree.html#xarray.DataTree) HTML representation: groups are now collapsible with item counts shown in labels, large trees are automatically truncated using `display_max_children` and `display_max_html_elements` options, and the Indexes section is now displayed (matching the text repr) ([PR10816](https://github.com/pydata/xarray/pull/10816)). By [Stephan Hoyer](https://github.com/shoyer).
- [`Dataset.set_xindex()`](generated/xarray.Dataset.set_xindex.html#xarray.Dataset.set_xindex) and [`DataArray.set_xindex()`](generated/xarray.DataArray.set_xindex.html#xarray.DataArray.set_xindex) automatically replace any existing index being set instead of erroring or needing needing to call `drop_indexes()` first ([PR11008](https://github.com/pydata/xarray/pull/11008)). By [Ian Hunt-Isaak](https://github.com/ianhi).
- Calling [`Dataset.sel()`](generated/xarray.Dataset.sel.html#xarray.Dataset.sel) or [`DataArray.sel()`](generated/xarray.DataArray.sel.html#xarray.DataArray.sel) on a 1-dimensional coordinate without an index will now automatically create a temporary [`PandasIndex`](generated/xarray.indexes.PandasIndex.html#xarray.indexes.PandasIndex) to perform the selection ([GH9703](https://github.com/pydata/xarray/issues/9703), [PR11029](https://github.com/pydata/xarray/pull/11029)). By [Ian Hunt-Isaak](https://github.com/ianhi).
- The minimum supported version of `h5netcdf` is now 1.4. Version 1.4.0 brings improved alignment between h5netcdf and libnetcdf4 in the storage of complex numbers ([PR11068](https://github.com/pydata/xarray/pull/11068)). By [Mark Harfouche](https://github.com/hmaarrfk).
- [`set_options()`](generated/xarray.set_options.html#xarray.set_options) now supports an `arithmetic_compat` option which determines how non-index coordinates of the same name are compared for potential conflicts when performing binary operations. The default for it is `arithmetic_compat='minimal'` which matches the existing behaviour ([PR10943](https://github.com/pydata/xarray/pull/10943)). By [Matthew Willson](https://github.com/mjwillson).
- Better ordering of coordinates when displaying xarray objects ([PR11091](https://github.com/pydata/xarray/pull/11091)). By [Ian Hunt-Isaak](https://github.com/ianhi), [Julia Signell](https://github.com/jsignell).
- Use `np.dtypes.StringDType` when reading Zarr string variables ([PR11097](https://github.com/pydata/xarray/pull/11097)). By [Julia Signell](https://github.com/jsignell).

### Breaking Changes[#](#id38)

- Change the default value for `chunk` in [`open_zarr()`](generated/xarray.open_zarr.html#xarray.open_zarr) to `_default` and remove special mapping of `"auto"` to `{}` or `None` in [`open_zarr()`](generated/xarray.open_zarr.html#xarray.open_zarr). If `chunks` is not set, the default behavior is the same as before. Explicitly setting `chunks="auto"` will match the behavior of `chunks="auto"` in [`open_dataset()`](generated/xarray.open_dataset.html#xarray.open_dataset) with `engine="zarr"` ([GH11002](https://github.com/pydata/xarray/issues/11002), [PR11010](https://github.com/pydata/xarray/pull/11010)). By [Julia Signell](https://github.com/jsignell).
- [`Dataset.identical()`](generated/xarray.Dataset.identical.html#xarray.Dataset.identical), [`DataArray.identical()`](generated/xarray.DataArray.identical.html#xarray.DataArray.identical), and [`testing.assert_identical()`](generated/xarray.testing.assert_identical.html#xarray.testing.assert_identical) now compare indexes. Two objects with identical data but different indexes will no longer be considered identical ([GH11033](https://github.com/pydata/xarray/issues/11033), [PR11035](https://github.com/pydata/xarray/pull/11035)). By [Ian Hunt-Isaak](https://github.com/ianhi).

### Bug Fixes[#](#id41)

- Ensure that `keep_attrs='drop'` and `keep_attrs=False` remove attrs from result, even when there is only one xarray object given to [`apply_ufunc()`](generated/xarray.apply_ufunc.html#xarray.apply_ufunc) ([GH10982](https://github.com/pydata/xarray/issues/10982), [PR10997](https://github.com/pydata/xarray/pull/10997)). By [Julia Signell](https://github.com/jsignell).
- `equals()` now uses floating point error tolerant `np.isclose` by default to handle accumulated floating point errors from slicing operations. Use `exact=True` for exact comparison ([PR11035](https://github.com/pydata/xarray/pull/11035)). By [Ian Hunt-Isaak](https://github.com/ianhi).
- Ensure the [`SeasonResampler`](generated/xarray.groupers.SeasonResampler.html#xarray.groupers.SeasonResampler) preserves the datetime unit of the underlying time index when resampling ([GH11048](https://github.com/pydata/xarray/issues/11048), [PR11049](https://github.com/pydata/xarray/pull/11049)). By [Spencer Clark](https://github.com/spencerkclark).
- Partially support pandas 3 default string indexes by coercing `pd.StringDtype` to `np.dtypes.StringDType` in `PandasIndexingAdapter` ([GH11098](https://github.com/pydata/xarray/issues/11098), [PR11102](https://github.com/pydata/xarray/pull/11102)). By [Julia Signell](https://github.com/jsignell).
- [`Dataset.eval()`](generated/xarray.Dataset.eval.html#xarray.Dataset.eval) now works with more than 2 dimensions ([PR11064](https://github.com/pydata/xarray/pull/11064)). By [Maximilian Roos](https://github.com/max-sixty).
- Fix [`where()`](generated/xarray.where.html#xarray.where) for `cupy.array` inputs ([PR11026](https://github.com/pydata/xarray/pull/11026)). By [Simon Høxbro Hansen](https://github.com/hoxbro).
- Fix `CombinedLock.locked()` to correctly call the underlying lock’s `locked()` method ([GH10843](https://github.com/pydata/xarray/issues/10843), [PR11022](https://github.com/pydata/xarray/pull/11022)). By [Samay Mehar](https://github.com/samay2504).
- Fix `DatasetGroupBy.map()` when grouping by more than one variable ([PR11005](https://github.com/pydata/xarray/pull/11005)). By [Joshua Gould](https://github.com/joshua-gould).
- Fix indexing bugs in [`CoordinateTransformIndex`](generated/xarray.indexes.CoordinateTransformIndex.html#xarray.indexes.CoordinateTransformIndex) ([PR10980](https://github.com/pydata/xarray/pull/10980)). By [Deepak Cherian](https://github.com/dcherian).
- Ensure the netCDF4 backend locks files while closing to prevent race conditions ([PR10788](https://github.com/pydata/xarray/pull/10788)). By [David Bold](https://github.com/dschwoerer).
- Improve error message when scipy is missing for [`NDPointIndex`](generated/xarray.indexes.NDPointIndex.html#xarray.indexes.NDPointIndex) ([PR11085](https://github.com/pydata/xarray/pull/11085)). By [Sakshee_D](https://github.com/Sakshee-D).
