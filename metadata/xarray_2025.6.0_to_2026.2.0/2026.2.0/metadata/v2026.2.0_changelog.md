## v2026.02.0 (Feb 13, 2026)[#](#v2026-02-0-feb-13-2026)

This release adds support for 1D coordinates in NDPointIndex for scattered point
indexing, switches all deprecation warnings to FutureWarning for better end-user
visibility, fixes silent data corruption when writing dask arrays to sharded Zarr
stores, and improves chunked array tokenization performance.

Thanks to the 11 contributors to this release:
Antonio Valentino, Chris Barker, Christine P. Chai, Deepak Cherian, Ewan Short, Harikrishna KP, Ian Hunt-Isaak, Julia Signell, Justus Magin, Kristian Kollsgård and Nick Hodgskin

### New Features[#](#id9)

- [`NDPointIndex`](generated/xarray.indexes.NDPointIndex.html#xarray.indexes.NDPointIndex) now supports coordinates with fewer dimensions than coordinate variables, enabling indexing of scattered points and trajectories where multiple coordinates (e.g., `x`, `y`) share a single dimension (e.g., `points`) ([GH10940](https://github.com/pydata/xarray/issues/10940), [PR11116](https://github.com/pydata/xarray/pull/11116)). By [Ian Hunt-Isaak](https://github.com/ianhi).

### Breaking Changes[#](#id11)

- When deprecating functionality, xarray has sometimes used `FutureWarning` and sometimes used `DeprecationWarning`. `DeprecationWarning` is not intended to be visible to end-users so this version of xarray switches to using `FutureWarning` everywhere ([PR11112](https://github.com/pydata/xarray/pull/11112)). By [Julia Signell](https://github.com/jsignell).

### Bug Fixes[#](#id13)

- Fix slicing with negative step ([GH11000](https://github.com/pydata/xarray/issues/11000), [PR11044](https://github.com/pydata/xarray/pull/11044)). By [Antonio Valentino](https://github.com/avalentino).
- Fix `.plot` error when using positional args with `col` and `row` ([GH11104](https://github.com/pydata/xarray/issues/11104), [PR11111](https://github.com/pydata/xarray/pull/11111)). By [Julia Signell](https://github.com/jsignell).
- Slightly amend [Xarray’s Zarr Encoding Specification doc](https://docs.xarray.dev/en/latest/internals/zarr-encoding-spec.html) for clarity, and provide a code comment in `xarray.backends.zarr._get_zarr_dims_and_attrs` referencing the doc ([GH8749](https://github.com/pydata/xarray/issues/8749), [PR11013](https://github.com/pydata/xarray/pull/11013)). By [Ewan Short](https://github.com/eshort0401).
- Fix silent data corruption when writing dask arrays to sharded Zarr stores. Dask chunk boundaries must now align with shard boundaries, not just internal Zarr chunk boundaries ([GH10831](https://github.com/pydata/xarray/issues/10831), [PR11117](https://github.com/pydata/xarray/pull/11117)). By [Kristian Kollsgård](https://github.com/kkollsga).
- Fix [`Dataset.sortby()`](generated/xarray.Dataset.sortby.html#xarray.Dataset.sortby) and [`DataArray.sortby()`](generated/xarray.DataArray.sortby.html#xarray.DataArray.sortby) placing NaN values at the beginning instead of the end when using `ascending=False` ([GH7358](https://github.com/pydata/xarray/issues/7358), [PR11118](https://github.com/pydata/xarray/pull/11118)). By [Kristian Kollsgård](https://github.com/kkollsga).
- Raise [`FileNotFoundError`](https://docs.python.org/3/library/exceptions.html#FileNotFoundError) instead of a confusing `ValueError` when [`open_dataset()`](generated/xarray.open_dataset.html#xarray.open_dataset) is called with a non-existent local file path ([GH10896](https://github.com/pydata/xarray/issues/10896), [PR11150](https://github.com/pydata/xarray/pull/11150)). By [Kristian Kollsgård](https://github.com/kkollsga).
- Improve error message when a chunk manager is not available, suggesting how to install the required package ([PR11056](https://github.com/pydata/xarray/pull/11056)). By [Julia Signell](https://github.com/jsignell).
- Raise [`ValueError`](https://docs.python.org/3/library/exceptions.html#ValueError) on slice-based selection of multi-index levels, which previously returned silently wrong results ([GH10534](https://github.com/pydata/xarray/issues/10534), [PR11168](https://github.com/pydata/xarray/pull/11168)). By [Harikrishna KP](https://github.com/Mr-Neutr0n).
